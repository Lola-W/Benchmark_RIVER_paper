# BAM placeholders

[BAM_PLACEHOLDERS.tsv](BAM_PLACEHOLDERS.tsv) lists the expected BAM filenames,
roles, and index naming. Paths in the table are relative to `variant_calling/`.
There are no empty BAM files and no sequencing data in this package. Supply or
link your own files at these locations; replace sample-sheet paths if needed.
The 16 PTA neurons and their matched bulk control belong in `pta/input/`.

Also supply the external germline VCFs listed in `../external_inputs.tsv`, with
their indexes. MosaicForecast and DeepMosaic instead use the PASS tumor-only
Mutect2 VCF generated by `illumina/mutect2_single/`. The extra VCF column in
`illumina/paired/samples.tsv` is retained from the source sample format; it is
read but not used by the included paired calling rules.
