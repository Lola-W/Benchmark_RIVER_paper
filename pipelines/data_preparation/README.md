# Data preparation

Stage-specific preparation scripts complement the [calling workflows](../variant_calling/README.md)
and [figure scripts](../../figure/README.md).

## Workflows

- [Downsampling and BAM selection](source/project/code/): downsampling, masks, and read filtering.
- [Coverage](source/project/code/coverage/): mosdepth distributions.
- [Candidate tables and annotations](source/regional_controls/02.merged/): union, genomic annotations, coordinate conversion, and raw-alignment pileups.
- [Intermediate table processing](source/regional_controls/03.merged_tsv/) and [repeat annotations](source/regional_controls/04.interm_tsv/).
- [Cleaned alignments](source/regional_controls/05.cleaned_bam/): assay-specific read selection and pileups.
- [Trinucleotide and depth distributions](source/regional_controls/06.trinuc_composition/): contexts, depth histograms, and ZIP/ZINB fitting.
- [Final filtering and VCF export](source/regional_controls/08.final_tsv/).
- [Mutation signatures](source/project/code/mut_signature/final/): SBS96 matrices, extraction, and assignment.
- [Benchmark table preparation](source/project/code/final_plot/bench_raw.Rmd): recorded R transformations; requires prepared objects and intermediate tables.

## Setup

Install the [software dependencies](SOFTWARE.md). From this directory:

```bash
python3 scripts/prepare_workspace.py
```

This creates path-resolved copies under `work/project/` and
`work/regional_controls/`; it does not run analyses or submit jobs. Use these
working copies rather than executing the source templates directly. Paths
starting `./work/`, `./inputs/`, and `./resources/` are relative to this package.
Use a package location without spaces or shell-special characters, and recreate
the working copies after moving the package. Differing existing work files are
not overwritten.

Supply the [alignment placeholders](inputs/ALIGNMENT_PLACEHOLDERS.tsv), indexes,
and resources referenced by the selected stage. Some input files are outputs of
earlier stages. Preserve each script's reference assembly and sample naming.
Activate the appropriate environment and set Slurm account/partition/QoS before
submitting jobs. Run each stage from its corresponding work directory.

## Trinucleotide matrix

After generating per-sample context counts, assemble the plotting input with:

```bash
python3 scripts/assemble_trinucleotide_matrix.py \
  --counts-dir work/regional_controls/06.trinuc_composition/01.trinuc32/merged \
  --output work/trinuc32_all_methods_wide.tsv
```

[config/trinucleotide_columns.tsv](config/trinucleotide_columns.tsv) is required
by this utility: it defines the 34 profile names and their count files. The
utility joins all 32 contexts and refuses existing output files. The final
plotting matrix is already supplied in `../../raw_data/`.

## Scope

The scripts require intermediate tables and are not a complete automated run
from raw alignments.

## Related software

See the [versioned RIVER citation](../../README.md#related-software-and-citation)
for the standalone cross-method read-support implementation. The source files
here retain historical study preparation; they are not replaced by RIVER and do
not establish that the supplied tables were generated by its packaged release.

ppmSeq callsets are external inputs from the
[separate calling repository](../variant_calling/ppmseq/README.md). The retained
`qc_ppm_calls_acgg.sh` consumes existing VCFs to update benchmark membership
flags; the ppmSeq read-selection and coverage scripts likewise do not call
variants. ppmSeq calling scripts are excluded from this package.
